## ✅ 已开启「自愈」

| 机制 | 作用 | 文件 |
|---|---|---|
| **守护进程** | 服务/隧道崩了 → 5 秒后自动重启 | `watchdog.js` |
| **固定子域名** | 重启后**网址不变**（被占用时会自动重试最多 2 分钟） | `start.js` |
| **开机自启** | 开机/登录后自动运行，不用手动开 | `安装开机自启.cmd` |

**开机自启需要你手动装一次**（沙箱没权限写系统目录）：

> 双击 `安装开机自启.cmd` → 看到「安装成功」即可。卸载就删掉 Startup 里的 `FitnessCloud.vbs`。

## ❗ 还是 503 / 打不开怎么办

503 = 本机服务没在跑（电脑关机、睡眠、或进程被结束）。

1. 双击 `启动.cmd`（或 `cd cloud && node start.js`）；
2. 等十几秒，看 `url.txt` 里打印的链接；
3. 因为子域名固定，**地址通常还是上面那条**。

> 电脑关机久了就一定会 503 —— 这是「自建」的天然限制。想要彻底不依赖电脑，见下方永久部署。

## 文件说明

```
site/                 网页（index / plan / tracker）
cloud/
  ├─ server.js        服务器：发网页 + 存数据（码云 / GitHub / 本机）
  ├─ start.js         启动：服务器 + 公网隧道（固定子域名）
  ├─ watchdog.js      守护：崩了自动重启
  ├─ 启动.cmd         手动启动（双击）
  ├─ 安装开机自启.cmd  安装开机自动启动（双击一次）
  ├─ 部署到云主机.md   永久部署分步教程（用码云当数据库）
  ├─ secret.txt       网址里的随机串（相当于密码）
  ├─ state.json       记录本体（本机模式）
  └─ url.txt          当前公网链接
```

## 永久部署（彻底不依赖本机）

⚠️ 云主机（Render 等）免费版磁盘是临时的，所以必须配合外部存储 —— 教程里用**你的码云仓库当数据库**，`server.js` 已内置支持（环境变量 `GT_TOKEN / GT_REPO / GT_PATH / GT_BRANCH`）。

## 安全提示

- 链接里 `e59137926fd8` 是随机密钥，**知道完整链接的人就能看/改记录**，别转发。
- 换密钥：删掉 `cloud/secret.txt` 重启（网址随之改变）。
- 备份：复制 `cloud/state.json`。
