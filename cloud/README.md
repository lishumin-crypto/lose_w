## ✅ 已开启「自愈」

| 机制 | 作用 | 文件 |
|---|---|---|
| **守护进程** | 服务/隧道崩了 → 自动重启；**每 60 秒探测公网链接，连续 2 次失败判定"隧道假死"并优雅重启** | `watchdog.js` |
| **SSH 反向隧道** | 走 localhost.run（比 loca.lt 稳，无"密码页"）；**网址每次重连会变，以 url.txt 为准** | `start.js` |
| **开机自启** | 开机/登录后自动运行，不用手动开 | `安装开机自启.cmd` |

**开机自启需要你手动装一次**（沙箱没权限写系统目录）：

> 双击 `安装开机自启.cmd` → 看到「安装成功」即可。卸载就删掉 Startup 里的 `FitnessCloud.vbs`。

## ❗ 打不开怎么办

**情况一：只是本机服务没在跑**（503 / 连接超时）——电脑关机、睡眠，或进程被结束。
1. 双击 `启动.cmd`（或 `cd cloud && node start.js`）；
2. 等 15–30 秒；
3. **打开 `url.txt` 里的新链接**（SSH 隧道重连会换网址，所以别用旧的）。

**情况二：打开了但看到英文的 "Tunnel website ahead / enter password" 页面** ——
那是旧隧道（loca.lt）的"密码页"，说明你用的是**旧网址**。以 `url.txt` 里的当前链接为准。

> 电脑关机久了就一定打不开 —— 这是「自建」的天然限制。想要固定网址、彻底不依赖电脑，见下方「永久部署」。

## 文件说明

```
site/                 网页（index / plan / tracker）
cloud/
  ├─ server.js        服务器：发网页 + 存数据（码云 / GitHub / 本机）
  ├─ start.js         启动：服务器 + 公网隧道（固定子域名）
  ├─ watchdog.js      守护：崩了自动重启
  ├─ 启动.cmd         手动启动（双击）
  ├─ 安装开机自启.cmd  安装开机自动启动（双击一次）
  ├─ 部署到云主机.md   永久部署分步教程（用码云当数据库）
  ├─ secret.txt       网址里的随机串（相当于密码）
  ├─ state.json       记录本体（本机模式）
  └─ url.txt          当前公网链接
```
