# 部署到 Render（固定网址，不依赖你的电脑）

**目标**：拿到一个**永不改变的网址**，手机/电脑随时打开，数据不丢。

**原理**：

```
        ┌─────────────── 拉代码（公开） ───────────────┐
        ▼                                              │
  Render 免费云主机  ──启动──►  server.js  ── 网页 ──►  你打开网址
        ▲                                              │
        └──── 读写数据（私有） ──►  码云私有仓库 state.json
```

**为什么要两个仓库？**
Render 只能拉**公开**仓库；但你的**体重、腰围**不能公开。所以：
- **代码仓库** `lose-w` → 设为**公开**（里面没有任何隐私，已确认）
- **数据仓库** `lose-w-data` → 保持**私有**（只存一个 state.json）

全程免费，约 10 分钟。

---

## 第 1 步：新建"数据"私有仓库

1. 打开 https://gitee.com → 右上 **+** → **新建仓库**
2. 仓库名称填：**`lose-w-data`**
3. 勾选 **私有**
4. **不要**勾"初始化仓库"（保持空仓库）
5. 点 **创建**

---

## 第 2 步：生成码云私人令牌

1. 右上头像 → **设置** → 左栏 **安全设置 → 私人令牌** → **生成新令牌**
2. 描述填 `fitness-plan`，权限**至少勾 `projects`**
3. 生成后**复制那串令牌**（只显示一次，先粘到记事本）

---

## 第 3 步：把代码仓库设为公开

1. 进入仓库 **`lose-w`** → **管理**（或"仓库设置"）→ **基本信息**
2. 找到 **是否开源 / 仓库公开** → 设为 **公开**
3. 保存

> 代码里已确认**没有任何密钥或个人数据**（`secret.txt`、`state.json` 都被 .gitignore 排除）。

---

## 第 4 步：在 Render 创建服务

1. 打开 https://render.com → 用 **GitHub 登录**（第三方登录就行）
2. 右上 **New +** → **Web Service**
3. 选 **Public Git repository**，地址填：

       https://gitee.com/llssmm/lose-w.git

   > ⚠️ **最容易错的一步**，务必是这一条：
   > - ✅ **HTTPS** 开头（`https://`），不是 `git@` 开头的 SSH 地址
   > - ✅ 填**代码仓库** `lose-w`（公开），**不要**填数据仓库 `lose-w-data`（私有，Render 拉不到，会报 `Invalid repository URL`）
   > - 数据仓库 `lose-w-data` 只通过下面的环境变量 `GT_REPO` 使用
   >
   > 若仍报错，试试去掉结尾的 `.git`：`https://gitee.com/llssmm/lose-w`

4. 按下表填写：

| 字段 | 填什么 |
|---|---|
| **Name** | `fitness-plan`（随意） |
| **Root Directory** | `cloud` ← **重要，别漏** |
| **Runtime** | `Node` |
| **Build Command** | `npm install` |
| **Start Command** | `node server.js` |
| **Instance Type** | `Free` |

5. 找到 **Environment Variables**，逐个 **Add Environment Variable**：

| Key | Value |
|---|---|
| `APP_SECRET` | `e59137926fd8`（可自定义成任意字母数字） |
| `GT_TOKEN` | 第 2 步复制的码云令牌 |
| `GT_REPO` | `llssmm/lose-w-data` |
| `GT_PATH` | `state.json` |
| `GT_BRANCH` | `master` |

6. 点 **Create Web Service**，等 2–3 分钟构建。

---

## 第 5 步：拿到固定网址

构建成功后，Render 页面顶部会显示域名，形如 `https://fitness-plan-xxxx.onrender.com`。

你的访问地址就是：

    https://fitness-plan-xxxx.onrender.com/a/e59137926fd8/

- 首页：上面的地址
- 打卡表：`…/a/e59137926fd8/tracker`
- 方案：`…/a/e59137926fd8/plan`

存进手机收藏夹即可。✅ 这个网址**永久不变**。

---

## 注意事项

- **免费版会休眠**：15 分钟没人访问就暂停，**下次打开要等 30–60 秒冷启动**（页面转圈是正常的）。
- **数据不会丢**：记录写进你的私有仓库 `lose-w-data/state.json`，重启/休眠都不受影响。想看或备份，直接看那个文件。
- **换密码**：改 Render 里的 `APP_SECRET` 并重新部署，网址随之改变。
- **撤销令牌**：码云设置里删除私人令牌即可（服务会停止同步）。
- **自测**：部署后打开 `…/a/<APP_SECRET>/tracker`，随便勾一个框，然后去码云看 `lose-w-data/state.json` 有没有更新。

## 遇到问题

| 现象 | 原因 / 处理 |
|---|---|
| 构建失败，提示找不到文件 | Root Directory 是否填了 `cloud` |
| 打开是 404 | 网址里的 `APP_SECRET` 是否和 Render 里一致 |
| 打卡能开但存不上（页头显示"同步失败"） | `GT_TOKEN` / `GT_REPO` 填错，或令牌没勾 `projects` |
| 打开很慢（30–60 秒） | 免费版冷启动，正常现象 |
