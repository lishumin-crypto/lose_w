# 部署到云主机（拿永久链接）

## 你现在的状态

- 代码已推到码云：**https://gitee.com/llssmm/lose-w**（私有仓库）
- 本机自建链接（已在跑）：`https://jfplan-2026a.loca.lt/a/e59137926fd8/`
- 服务器代码 `cloud/server.js` 已支持三种存储：**码云 Gitee / GitHub / 本机文件**，按环境变量自动选择。

> **为什么不能直接把服务丢到云主机？** Render 等免费云主机的磁盘是**临时**的（休眠/重启清空），记录会反复丢失。所以必须把数据存到你的**码云仓库**里 —— 下面就是这么做的。

---

## 第一步：生成码云私人令牌

1. 登录码云 → 右上头像 → **设置**
2. 左栏 **安全设置 → 私人令牌** → **生成新令牌**
3. 描述随便填（如 `fitness-plan`），权限**至少勾选 `projects`**
4. 生成后**复制那串令牌**（只显示一次）。

---

## 第二步：云主机建服务

以 **Render** 为例（其他 Node 平台同理）：

1. https://render.com → GitHub 登录（第三方登录即可）
2. **New +** → **Web Service** → 选 **Public Git repository**，填：

       https://gitee.com/llssmm/lose-w.git

   ⚠️ **Render 只能拉公开仓库**。若 `lose-w` 是私有的，先在码云 **仓库设置 → 基本信息 → 开源（设为公开）**。
   代码里没有任何密钥（`secret.txt` / `state.json` 已被 `.gitignore` 排除），公开是安全的。

3. 填参数：

| 字段 | 值 |
|---|---|
| Name | `fitness-plan` |
| Root Directory | `cloud` |
| Runtime | Node |
| Build Command | `npm install` |
| Start Command | `node server.js` |
| Instance Type | Free |

4. **Environment Variables** 逐个添加：

| Key | Value |
|---|---|
| `APP_SECRET` | `e59137926fd8`（可自定义） |
| `GT_TOKEN` | 第一步复制的码云令牌 |
| `GT_REPO` | `llssmm/lose-w` |
| `GT_PATH` | `state.json` |
| `GT_BRANCH` | `master` |

5. 点 **Create Web Service**，等 2–3 分钟。

---

## 第三步：拿到永久网址

部署成功后会得到形如 `https://fitness-plan-xxxx.onrender.com` 的域名，你的访问地址：

    https://fitness-plan-xxxx.onrender.com/a/e59137926fd8/

- 首页：上面的地址
- 打卡表：`…/a/e59137926fd8/tracker`
- 方案：`…/a/e59137926fd8/plan`

数据会写进码云仓库里的 `state.json`，**云主机重启/休眠都不会丢**。

---

## 注意事项

- **Render 免费版会休眠**：15 分钟无访问则暂停，下次打开要等 30–60 秒冷启动，属正常。
- **不想公开仓库？** 那就继续用本机自建这条链接（`cloud/启动.cmd` + `安装开机自启.cmd`），或换用支持私有仓库的国内云主机（阿里云函数计算 / 腾讯云 CloudBase 等，配置更复杂）。
- **换密钥**：改 `APP_SECRET` 重新部署，网址随之变化。
- **撤销令牌**：码云设置里删除私人令牌即可。
