# 部署到 Render（固定网址，不依赖你的电脑）

**目标**：拿到一个**永不改变的网址**，手机/电脑随时打开，数据不丢。

---

## ⚠️ 先看这条（我踩过的坑）

**Render 只支持 GitHub / GitLab / Bitbucket 三个 Git 平台，不支持码云（Gitee）。**
在 Render 里填 `https://gitee.com/...` 会直接报 **`Invalid repository URL`** —— 不是格式问题，是平台不支持。

所以分工是：

```
  代码  →  GitHub（Render 从这里拉）
  数据  →  码云私有仓库 lose-w-data（已建好，不浪费）
```

```
        ┌────────── 拉代码 ──────────┐
        ▼                            │
  Render 免费云主机 ──► server.js ──► 你打开网址
        ▲                            │
        └──── 读写数据 ──► 码云私有仓库 state.json
```

---

## 第 1 步：注册 GitHub

https://github.com → Sign up（免费）。有账号就跳过。

## 第 2 步：代码已推送到 GitHub ✅（已完成）

代码已从本机直接推到：

    https://github.com/lishumin-crypto/lose_w     （公开，分支 master）

以后要更新代码，本机执行 `git push github master` 即可。

## 第 3 步：确认码云数据仓库已就绪（你已完成 ✅）

- 私有仓库 **`lose-w-data`** 已创建
- 码云 **私人令牌**（权限 `projects`）已生成并复制

## 第 4 步：在 Render 创建服务

1. 打开 https://render.com → 用 **GitHub 登录**
2. 右上 **New +** → **Web Service**
3. 这次用 **Public Git Repository** 或 **Git Provider** 都行（仓库是公开的），地址填：

       https://github.com/lishumin-crypto/lose_w.git

   > 分支（Branch）选 **`master`**。

4. 按表填写：

| 字段 | 填什么 |
|---|---|
| **Name** | `fitness-plan`（随意） |
| **Root Directory** | `cloud` ← **重要，别漏** |
| **Runtime** | `Node` |
| **Build Command** | `npm install` |
| **Start Command** | `node server.js` |
| **Instance Type** | **Free** |

5. **Environment Variables** 加这 5 条：

| Key | Value |
|---|---|
| `APP_SECRET` | `e59137926fd8`（可自定义） |
| `GT_TOKEN` | 码云私人令牌 |
| `GT_REPO` | `llssmm/lose-w-data` |
| `GT_PATH` | `state.json` |
| `GT_BRANCH` | `master` |

6. 点 **Create Web Service**，等 2–3 分钟。

## 注意事项

- **数据必须放"另一个"仓库**：如果让服务器把 `state.json` 写回它自己部署用的仓库，**每次勾选都会触发重新部署**。所以数据放码云的 `lose-w-data`。
- **免费版会休眠**：15 分钟没人访问就暂停，下次打开要等 30–60 秒冷启动（正常）。
- **换密码**：改 `APP_SECRET` 重新部署。
- **自测**：打开 `…/a/<APP_SECRET>/tracker` 勾一个框 → 去码云看 `lose-w-data/state.json` 有没有更新。

## 排错表

| 现象 | 原因 / 处理 |
|---|---|
| `Invalid repository URL` | 填了码云地址。必须用 GitHub 仓库（第 2 步） |
| 构建失败，找不到文件 | Root Directory 是否填了 `cloud` |
| 打开是 404 | 网址里的 `APP_SECRET` 和 Render 里的不一致 |
| 能开但存不上（页头"同步失败"） | `GT_TOKEN` / `GT_REPO` 错，或令牌没勾 `projects` |
| 打开慢（30–60 秒） | 免费版冷启动，正常 |
